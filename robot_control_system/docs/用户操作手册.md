## 1. 系统概述

### 1.1 系统简介

珞石 SR5-C 机器人控制系统是一套基于 Python 和 PyQt5 开发的六轴机器人全栈控制解决方案。系统集成了3D数字孪生、运动学计算、状态机控制、码垛路径规划等功能。

### 1.2 主要功能

- **3D数字孪生**: 实时显示机器人姿态和运动轨迹
- **运动学计算**: 正逆运动学求解、雅可比矩阵计算
- **状态机控制**: 完整的设备状态管理
- **码垛规划**: 自动生成码垛点位和轨迹
- **虚拟仿真**: 支持无实机情况下的仿真测试
- **报警管理**: 报警记录、确认和历史查询

### 1.3 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11, Linux, macOS |
| Python | 3.8 或更高版本 |
| 内存 | 8GB 或更多 (推荐16GB) |
| 显卡 | 支持 OpenGL 3.3+ |
| 分辨率 | 1920x1080 或更高 (推荐) |

## 4. 基本操作

### 4.1 系统启动流程

1. **启动程序**: 运行 `python main.py`
2. **等待初始化**: 系统自动完成初始化
3. **检查状态**: 确认"连接状态"显示"已连接"

### 4.2 伺服使能

1. 确认系统状态为 "READY"
2. 点击 "伺服使能" 按钮
3. 等待状态变为 "ENABLED"
4. 伺服状态指示器显示绿色

### 4.3 回原点操作

1. 确认伺服已使能
2. 点击 "回原点" 按钮
3. 在弹出的确认对话框中点击 "是"
4. 等待回原点完成，状态变为 "STANDBY"

### 4.4 手动点动

1. 确认状态为 "STANDBY"
2. 切换到 "关节控制" 选项卡
3. 按住 +/- 按钮进行点动
4. 或使用滑块/数值输入调整角度

### 4.5 速度调节

1. 使用速度滑块调节运动速度
2. 范围: 1% - 100%
3. 建议调试时使用较低速度 (10-30%)

### 4.6 急停操作

**警告**: 急停用于紧急情况，会立即停止所有运动并禁止伺服。

1. 点击红色 "急停" 按钮
2. 所有运动立即停止
3. 状态变为 "EMERGENCY_STOP"
4. 需要复位故障后才能继续操作

## 5. 码垛程序

### 5.1 配置码垛参数

1. 切换到 "码垛程序" 选项卡
2. 设置行数 (1-10)
3. 设置列数 (1-10)
4. 设置层数 (1-5)
5. 确认总数显示正确

### 5.2 运行码垛程序

1. 确认状态为 "STANDBY"
2. 点击 "启动" 按钮
3. 观察进度条和当前循环数
4. 3D视窗显示机器人运动

### 5.3 暂停和继续

1. 运行中点击 "暂停" 可暂停程序
2. 暂停后点击 "启动" 继续执行
3. 点击 "停止" 终止程序

## 6. 故障排除

### 6.1 常见问题

#### 问题: 程序无法启动

**原因**: Python依赖未安装

**解决方案**:
```bash
pip install -r requirements.txt
```

#### 问题: 3D视窗显示空白

**原因**: PyVista未安装或显卡不支持

**解决方案**:
```bash
pip install pyvista pyvistaqt
```

#### 问题: 伺服无法使能

**可能原因**:
- 存在未清除的故障
- 状态机不在正确状态

**解决方案**:
1. 查看报警信息
2. 清除所有报警
3. 复位故障
4. 重新尝试使能

### 6.2 报警处理

1. 查看报警信息区域
2. 点击 "确认报警" 确认
3. 点击 "清除报警" 清除已确认的报警
4. 如有严重故障，需复位后重新操作

### 7.2 状态说明

| 状态 | 说明 | 允许操作 |
|------|------|----------|
| IDLE | 空闲 | 扫描设备 |
| SCANNING | 扫描中 | 等待 |
| READY | 就绪 | 使能伺服 |
| ENABLED | 已使能 | 回原点、禁止 |
| HOMING | 回原点中 | 急停 |
| STANDBY | 待机 | 点动、自动、回原点 |
| JOG | 点动模式 | 手动操作 |
| AUTO_RUN | 自动运行 | 暂停、停止 |
| PAUSED | 暂停 | 继续、停止 |
| FAULT | 故障 | 复位 |
| EMERGENCY_STOP | 急停 | 解除急停 |
