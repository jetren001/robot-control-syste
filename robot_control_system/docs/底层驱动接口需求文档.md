## 3. EtherCAT 设备信息

### 3.1 从站配置

| 从站ID | 设备名称 | 产品代码 | 说明 |
|--------|----------|----------|------|
| 0-5 | ROKAE xServo | 0x00016101 | 6轴伺服驱动器 |
| 6 | ROKAE-SR_KEY | 0x00000002 | IO扩展模块 |

### 3.2 PDO 映射

#### RxPDO (主站发送到从站)

| 索引 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0x607A | Target Position | INT32 | 目标位置 (脉冲) |
| 0x60FF | Target Velocity | INT32 | 目标速度 |
| 0x6040 | Control Word | UINT16 | 控制字 |
| 0x6060 | Mode of Operation | INT8 | 运行模式 |

#### TxPDO (从站发送到主站)

| 索引 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0x6064 | Actual Position | INT32 | 实际位置 (脉冲) |
| 0x606C | Actual Velocity | INT32 | 实际速度 |
| 0x6041 | Status Word | UINT16 | 状态字 |
| 0x603F | Error Code | UINT16 | 错误代码 |

### 4.4 虚实切换接口

```python
class DriverMode(Enum):
    """驱动模式枚举"""
    VIRTUAL = "virtual"  # 虚拟仿真模式
    REAL = "real"        # 真实硬件模式

class ModeManager:
    """虚实切换管理器"""
    
    def __init__(self):
        self._current_mode = DriverMode.VIRTUAL
    
    def switch_mode(self, mode: DriverMode) -> bool:
        """
        切换驱动模式
        
        Args:
            mode: 目标模式 (VIRTUAL/REAL)
            
        Returns:
            bool: 切换成功返回True
        """
        pass
    
    def get_current_mode(self) -> DriverMode:
        """
        获取当前模式
        
        Returns:
            DriverMode: 当前模式
        """
        return self._current_mode
    
    def is_virtual_mode(self) -> bool:
        """
        是否为虚拟模式
        
        Returns:
            bool: 虚拟模式返回True
        """
        return self._current_mode == DriverMode.VIRTUAL
```

## 5. 数据结构定义

```python
from dataclasses import dataclass
from enum import Enum
from typing import List, Optional

class NetworkState(Enum):
    """EtherCAT网络状态"""
    INIT = 0
    PREOP = 1
    SAFEOP = 2
    OP = 3
    ERROR = -1

class AxisState(Enum):
    """轴状态"""
    NOT_READY = 0
    SWITCH_ON_DISABLED = 1
    READY_TO_SWITCH_ON = 2
    SWITCHED_ON = 3
    OPERATION_ENABLED = 4
    QUICK_STOP_ACTIVE = 5
    FAULT_REACTION_ACTIVE = 6
    FAULT = 7

@dataclass
class DeviceInfo:
    """设备信息"""
    slave_id: int
    name: str
    product_code: int
    revision: int
    vendor_id: int
    state: NetworkState

@dataclass
class AxisStatus:
    """轴状态信息"""
    axis_id: int
    state: AxisState
    position: float
    velocity: float
    torque: float
    error_code: int
    enabled: bool
    in_position: bool

@dataclass
class SystemStatus:
    """系统状态信息"""
    connected: bool
    network_state: NetworkState
    mode: DriverMode
    all_enabled: bool
    any_error: bool
    axis_statuses: List[AxisStatus]

@dataclass
class ErrorInfo:
    """错误信息"""
    axis_id: int
    error_code: int
    error_message: str
    timestamp: float
```

## 6. 错误代码定义

| 错误代码 | 名称 | 说明 | 处理方式 |
|----------|------|------|----------|
| 0x0000 | NO_ERROR | 无错误 | - |
| 0x2311 | OVER_CURRENT | 过流 | 检查负载 |
| 0x3110 | OVER_VOLTAGE | 过压 | 检查电源 |
| 0x3120 | UNDER_VOLTAGE | 欠压 | 检查电源 |
| 0x4210 | OVER_TEMPERATURE | 过温 | 降温后重试 |
| 0x5113 | ENCODER_ERROR | 编码器错误 | 检查编码器 |
| 0x6010 | POSITION_LIMIT | 位置超限 | 检查限位 |
| 0x7300 | COMMUNICATION_ERROR | 通信错误 | 检查连接 |
| 0x8611 | FOLLOWING_ERROR | 跟随误差 | 降低速度 |
| 0xFF00 | EMERGENCY_STOP | 急停触发 | 解除急停 |

## 7. 使用示例

```python
from driver import RobotController, DriverMode, ModeManager

# 创建控制器实例
robot = RobotController()
mode_manager = ModeManager()

# 设置为虚拟模式
mode_manager.switch_mode(DriverMode.VIRTUAL)

# 连接机器人
if robot.connect():
    print("连接成功")
    
    # 使能所有轴
    if robot.enable_all():
        print("使能成功")
        
        # 回原点
        robot.home()
        
        # 移动到指定关节位置
        robot.set_joint_positions([0, -45, 90, 0, 45, 0], velocity=50)
        
        # 获取TCP位置
        pos, ori = robot.get_tcp_position()
        print(f"TCP位置: {pos}, 姿态: {ori}")
        
    # 禁止并断开
    robot.disable_all()
    robot.disconnect()
```
