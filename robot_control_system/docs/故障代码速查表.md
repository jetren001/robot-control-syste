## 错误代码 (E系列)

需要立即处理的严重故障。

| 代码 | 名称 | 原因分析 | 解决方案 |
|------|------|----------|----------|
| E001 | 过流保护 | 电机负载过大、短路、驱动器故障 | 1. 检查负载是否超限<br>2. 检查电机接线<br>3. 降低运动速度 |
| E002 | 过压保护 | 供电电压过高、再生能量过大 | 1. 检查电源电压<br>2. 检查制动电阻<br>3. 降低减速度 |
| E003 | 欠压保护 | 供电电压不足、电源容量不够 | 1. 检查电源连接<br>2. 检查电源容量<br>3. 检查线缆压降 |
| E004 | 过温保护 | 环境温度过高、散热不良、长时间高负载运行 | 1. 检查环境温度<br>2. 改善散热条件<br>3. 降低运行频率<br>4. 等待冷却后重试 |
| E005 | 编码器故障 | 编码器损坏、接线问题、电磁干扰 | 1. 检查编码器接线<br>2. 检查屏蔽接地<br>3. 更换编码器 |
| E006 | 位置超限 | 软限位触发、机械干涉、回原点失败 | 1. 检查位置是否超出范围<br>2. 检查机械限位<br>3. 重新回原点 |
| E007 | 通信故障 | EtherCAT断线、从站丢失、通信超时 | 1. 检查网线连接<br>2. 检查从站状态<br>3. 重新扫描设备 |
| E008 | 跟随误差 | 负载过大、速度过快、参数不当 | 1. 检查负载<br>2. 降低运动速度<br>3. 调整PID参数 |
| E009 | 急停触发 | 用户按下急停、外部急停信号 | 1. 解除急停按钮<br>2. 检查外部急停信号<br>3. 复位故障 |
| E010 | 使能失败 | 驱动器故障、安全回路未闭合 | 1. 检查驱动器状态<br>2. 检查安全回路<br>3. 复位后重试 |

## 警告代码 (W系列)

需要关注但不影响运行的警告。

| 代码 | 名称 | 原因分析 | 解决方案 |
|------|------|----------|----------|
| W001 | 温度预警 | 温度接近上限 | 1. 关注温度变化<br>2. 改善散热<br>3. 考虑降低负载 |
| W002 | 电压偏低 | 供电电压接近下限 | 1. 检查电源状态<br>2. 减少同时运行的轴数 |
| W003 | 负载偏高 | 负载接近额定值 | 1. 检查负载<br>2. 考虑降速运行 |
| W004 | 电池电量低 | 编码器电池电量不足 | 1. 更换编码器电池<br>2. 注意备份位置数据 |
| W005 | 润滑提醒 | 运行时间超过润滑周期 | 1. 执行润滑保养<br>2. 重置润滑计时器 |

## 故障处理流程

```
┌─────────────────────────────────────┐
│          发生故障                    │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│   1. 确认报警信息 (查看代码和描述)    │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│   2. 查阅故障代码表确定原因          │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│   3. 排除故障原因                    │
│      - 检查硬件连接                  │
│      - 检查运行参数                  │
│      - 检查外部条件                  │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│   4. 确认报警                        │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│   5. 清除报警                        │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│   6. 复位故障 (状态机)               │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│   7. 重新使能并验证                  │
└─────────────────────────────────────┘
```
